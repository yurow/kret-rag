### 核心改进

#### **修改前**（简单版）

```python
system_content = f"""你是一个智能问答助手。请基于以下参考信息回答问题。

**要求**：
1. 如果参考信息足以回答问题，请给出准确、详细的回答
2. 如果参考信息不足以回答问题，请明确说明"根据现有资料，我无法回答这个问题"

**参考信息**：
{rag_context}
"""
```

**问题**：
- ❌ 约束不够明确
- ❌ LLM可能仍然会编造答案
- ❌ 没有明确的判断流程

---

#### **修改后**（防幻觉强化版）

```python
system_content = f"""你是一个智能问答助手。请基于以下参考信息回答问题。

**核心原则**：
1. **严格基于参考信息回答**：你的所有回答必须完全基于提供的参考信息
2. **禁止编造答案**：如果参考信息中没有相关信息，必须如实回答「知识库暂无相关配置信息」
3. **禁止自行发挥**：不要使用参考信息之外的知识来回答问题
4. **引用来源**：回答时要明确标注信息来源（如：[引用1]、[引用2]）
5. **保持准确**：确保回答与参考信息一致，不夸大、不臆测

**判断流程**：
- 第一步：仔细阅读参考信息
- 第二步：判断参考信息是否足以回答用户问题
- 第三步：如果足够 → 给出详细准确的回答，并标注引用
- 第四步：如果不足 → 直接回复「知识库暂无相关配置信息」

**参考信息**：
{rag_context}

**重要提醒**：
- 如果参考信息与问题无关，不要强行回答
- 如果参考信息不完整，不要补充缺失的信息
- 宁可说不知道，也不要编造答案
"""
```

**优势**：
- ✅ **明确的禁止指令**：多次强调"禁止编造"
- ✅ **标准回复模板**：统一使用「知识库暂无相关配置信息」
- ✅ **清晰的判断流程**：四步决策流程
- ✅ **多重约束**：从多个角度限制LLM行为
- ✅ **心理暗示**："宁可说不知道，也不要编造答案"

---

## 🔍 工作原理

### **Prompt Engineering 策略**

1. **明确边界** - "严格基于参考信息回答"
2. **负面约束** - "禁止编造"、"禁止自行发挥"
3. **标准化输出** - 统一的拒绝话术
4. **流程引导** - 分步骤的思考过程
5. **重复强调** - 在多处重申关键约束

## 💡 最佳实践建议

### 1. **配合低温度参数使用**

在调用LLM时，设置较低的 `temperature` 值：

```python
response = await llm_service.generate_response(
    messages=conversation_history,
    temperature=0.3  # 降低随机性，提高一致性
)
```

**推荐值**：
- RAG场景：`0.2-0.5`（更保守、更准确）
- 创意写作：`0.7-1.0`（更有创造性）

---

### 2. **监控拒绝率**

统计LLM返回「知识库暂无相关配置信息」的频率：

```python
if response == "知识库暂无相关配置信息":
    # 记录日志，分析原因
    logger.warning(f"用户问题未找到答案: {query}")
    
    # 可能的原因：
    # 1. 检索质量差 → 优化embedding模型
    # 2. 阈值过高 → 降低score_threshold
    # 3. 知识库确实缺少相关内容 → 补充文档
```

---

### 3. **优化检索质量**

防幻觉的前提是**检索到相关信息**。如果检索失败，LLM只能拒绝回答。

**优化方向**：
- ✅ 使用查询重写（Query Rewriting）
- ✅ 启用混合检索（Hybrid Search）
- ✅ 启用重排序（Rerank）
- ✅ 调整相似度阈值（score_threshold）

## 🎯 进一步优化建议

### 1. **添加置信度评分**

让LLM在回答时附带置信度：

```python
system_content += """
**置信度评估**：
在回答末尾标注置信度等级：
- 【高置信度】：参考信息充分支持回答
- 【中置信度】：参考信息部分支持，但可能不完整
- 【低置信度】：参考信息有限，回答可能不准确
"""
```

---

### 2. **提供相关但不完全匹配的内容**

当检索结果相关性较低时：

```python
system_content += """
**处理低相关性内容**：
如果参考信息与问题的相关性较低（相似度 < 0.5），请在回答开头说明：
"以下内容可能与您的问题相关，但匹配度不高..."
"""
```

---

### 3. **多轮对话中的上下文记忆**

在多轮对话中，记住之前的拒绝：

```python
# 如果之前已经拒绝过类似问题
if previous_refusal_count > 2:
    system_content += """
**注意**：用户之前询问过类似问题，但知识库中没有相关信息。
请不要改变立场，继续保持「知识库暂无相关配置信息」。
"""
```
